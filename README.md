# debug-dairy 🪲📓

A running log of the issues I hit — and how I solved them — while grinding through DSA in Java, full-stack projects, and AI/ML experiments.

This isn't a solutions dump. It's the struggle, documented: the wrong approach I tried first, the bug that ate an hour, the "oh, *that's* why" moment. Future-me (and anyone else stuck on the same thing) gets the real path, not the clean one.

## What's in here

This repo currently tracks **DSA patterns** — the recurring techniques that show up across LeetCode/interview-style problems (Two Pointers, Sliding Window, and others as I cover them). Each pattern gets its own space to log:

- The problem that exposed a gap in my understanding
- What I tried first, and why it broke
- The actual fix / correct approach
- The "aha" — what I'd tell past-me to save the hour

## Problem: <name / link>

## Why this exists

I'm working through DSA with a struggle-first approach — attempt cold, fail, diagnose, retry — rather than pattern-matching off a solution I already saw. This repo is where the failures get written down, because the failure is usually more instructive than the accepted solution.

Patterns get added here as I work through them; this README will grow alongside the folder list.
